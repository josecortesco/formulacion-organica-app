Controles

  • WASD ↑↓←→ Mover el cursor
  • C Espacio Poner carbono
  • O Poner oxígeno
  • N Poner nitrógeno (otra vez: NO₂)
  • X Poner halógeno (otra vez: Cl → Br → I → F)
  • Q Supr Quitar átomo
  • Mayús + dirección Enlace simple → doble → triple → sin enlace
  • Z Deshacer
  • + − Zoom (también con la rueda)
  • L Numerar la cadena (modo libre)
  • Enter Comprobar / siguiente (práctica)
  • V Ver la solución tras un fallo
  • Esc Volver al menú · cerrar esta ventana
